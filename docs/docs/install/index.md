## Installation

Goma Gateway ships as a single binary and as the `jkaninda/goma-gateway`
container image. Choose the guide for your platform:

- [Docker](docker.md) — run the container directly or with Docker Compose.
- [Kubernetes](kubernetes.md) — deploy with standard Kubernetes resources, or
  with the [Goma Gateway Operator](../operator-manual/installation.md).

New to Goma Gateway? The [Quickstart](../quickstart/index.md) walks through
generating, validating and running a first configuration.
